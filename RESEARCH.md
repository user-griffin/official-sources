# Implementation research

Checked on 2026-08-02 against primary documentation and current source.

- **Nuvio:** the current [`Stream`](https://github.com/NuvioMedia/NuvioTV/blob/main/app/src/main/java/com/nuvio/tv/domain/model/Stream.kt) and [`StreamResponseDto`](https://github.com/NuvioMedia/NuvioTV/blob/main/app/src/main/java/com/nuvio/tv/data/remote/dto/StreamResponseDto.kt) accept standard `name`, `title`, `description`, `externalUrl`, and `behaviorHints`. An external-only stream is deliberately non-autoplayable. [`PlayerRuntimeControllerStreams`](https://github.com/NuvioMedia/NuvioTV/blob/main/app/src/main/java/com/nuvio/tv/ui/screens/player/PlayerRuntimeControllerStreams.kt) opens it with `ACTION_VIEW`, `CATEGORY_BROWSABLE`, and a new-task flag. Android decides whether a verified HTTPS App Link opens an installed app or browser. Custom schemes can work only when a matching app intent filter exists, so this addon conservatively emits validated HTTPS URLs.
- **Grouping/order:** Nuvio groups responses as `AddonStreams`; [`StreamAutoPlaySelector`](https://github.com/NuvioMedia/NuvioTV/blob/main/app/src/main/java/com/nuvio/tv/core/player/StreamAutoPlaySelector.kt) orders addon groups from the installed-addon order. Result order inside Official Sources is retained. Put Official Sources first by moving it to the top of Nuvio's installed addon list; the addon cannot override cross-addon ordering.
- **Stremio protocol:** the current [protocol](https://github.com/Stremio/stremio-addon-sdk/blob/master/docs/protocol.md) requires permissive CORS for HTTP addons. The [stream response spec](https://github.com/Stremio/stremio-addon-sdk/blob/master/docs/api/responses/stream.md) defines `externalUrl` as an external webpage (for example Netflix). The manifest declares a typed `stream` resource with IMDb `tt` and TMDB `tmdb:` prefixes. The official [WatchHub descriptor](https://github.com/Stremio/stremio-official-addons/blob/master/index.json) remains useful prior art for an external-link-only stream addon.
- **Watchmode:** API OpenAPI 1.1.7 is published at [the API explorer](https://api.watchmode.com/docs). Use `X-API-Key`, not a query parameter. `/sources` returns provider IDs, types, regions and logos; `/search` maps IMDb, TMDB movie, and TMDB TV IDs; `/title/{id}/details` includes `network_names` used conservatively to identify the title's home service; `/title/{id}/sources` returns title availability; `/title/{id}/episodes?season=&episode=&regions=` returns episode sources. Source URLs include `android_tv_url`, `android_url`, and `web_url`. The adapter checks episode numbers, validates every response, and rejects paid-plan placeholders.
- **Plan/attribution:** the free-key page currently advertises 2,500 monthly requests and up to three countries, but no iOS/Android deep links or episode-level links. On the free plan, a validated series-page fallback is the practical episode behavior and must be labeled as such. [Watchmode terms](https://api.watchmode.com/tc) allow caching non-image API data for at most 30 days and may require linked attribution depending on plan. This UI links attribution wherever provider data is shown and caches for no more than seven days. Logo URLs are shown directly and never downloaded or rehosted.
- **Railway:** [Railway config-as-code](https://docs.railway.com/config-as-code/reference) supports build/start commands and health checks; [its Node/Express guide](https://docs.railway.com/guides/deploy-node-express-api-with-auto-scaling-secrets-and-zero-downtime) expects `PORT` and a health endpoint. The server binds `0.0.0.0`, derives its public origin from `PUBLIC_BASE_URL` or `RAILWAY_PUBLIC_DOMAIN`, and shuts down on `SIGTERM`/`SIGINT`.

No provider pages or JustWatch data are scraped. The server never fetches returned destination URLs.
